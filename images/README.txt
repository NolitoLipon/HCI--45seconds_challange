PICTURES FOR YOUR WEBSITE
=========================
Keep index.html and this "images" folder together (same place, same level).
Every picture below is OPTIONAL except the ones already included.
If a picture is missing, the page shows a colored placeholder, so nothing breaks.
To change a picture: save a new image with the SAME FILE NAME in the SAME FOLDER.
File names must be lowercase and match exactly.
